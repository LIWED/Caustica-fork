# 普通间接反射平滑实验

- 授权：用户在 ITRP 对照与正则化建议后要求继续研究或实践；按已提出的可控实验推进，无需重复确认。保留当前工作区历史修改，不提交或切换分支。
- 目标：验证普通反光材质的后续间接路径是否主导颗粒与尖峰；同时测量亮度/反射变化，避免把磨糊画面当成收敛。
- 选择：先做局部路径正则化，暂不移植 ITRP 体素缓存或后期滤波；后两者涉及更大的几何/重建架构且难以隔离原因。
- 视频设置新增“离线间接反射平滑”：关闭、轻度、较强；默认关闭。切换重置历史，实时渲染不受影响。
- 路径从相机开始时不调整；玻璃/水的理想界面不设置非镜面历史；发生普通 BSDF 或粒子漫散射后才允许调整后续普通 PBR。当前普通 GGX 都是有限粗糙度，因此其任一有效采样属于非 delta 散射。
- 微表面 alpha=roughness² 小于 0.3 时：alpha'=clamp(2*alpha, floor, 0.3)，轻度 floor=0.04，较强 floor=0.1；较粗材质保持不变。返回 sqrt(alpha')。关闭或无非 delta 历史时逐值原样返回。
- 在当前顶点第一次光照/BSDF计算前调整唯一局部 rough，NEE、完整混合 PDF、采样、MIS、ray-cone 后续传播使用同值。保持首个可见普通表面及纯理想界面链后的首次普通表面原材质。
- 使用 WorldPush.flags 的 bits7–8 传模式，不扩 ABI；相同模式编码进入离线输入签名。路径日志的既有 world flags 记录模式，步内 roughness 保留原材质值，分析器必须用模式和非 delta 历史重建实际粗糙度。
- 不改变水/玻璃 BSDF、几何法线、光线偏移、光源模型或累积。水体及其他缺陷并不保证改善。此为有偏选项，间接高光/焦散可能改变。
- 验证：实际函数抽取的模式/边界/状态测试、解析两段光路的均值与方差实验、关模式复现旧值、主表面和理想链不修改、配套 PDF/NEE 绑定、历史重置、回归与完整构建。
- 实验不等于 GPU 验收。游戏用同视角/分辨率/曝光/时间比较关闭与开启，优先原反光房间，保留低太阳水池及人工光源室内。验证候选后按既有授权自动部署且保留旧 JAR。
