- [x] 薄玻璃天体 NEE：有界 radiance walker 复用真实玻璃命中、逐界面 Fresnel/tint；尊重剩余反弹预算，保存恢复 payload。
- [x] 玻璃直传保留天体配对 PDF，反射重置；避免共享状态意外改变旧静态光源估计器。
- [x] 扩大诊断：基础天空、解析天体、经过玻璃透射/反射和水透射/反射的天体、末跳直接天体贡献。采样不受视图影响。
- [x] 原回归、新增数值与负面测试、完整构建、打包资源核验；更新 PROJECT/BUGS/CHANGELOG。

## 设计约束

- 不加入默认亮度 clamp 或重构为 wavefront。
- 能量衰减需有白炉上界，不能仅凭一组均值判定守恒；保守衰减可能使掠射漫反射变暗，记录画面影响。
- 玻璃是直线薄片，水折射继续阻断直线 NEE。传输模型、配对权重与深度预算必须同时匹配。
- 新诊断是贡献分层；完整 GPU 路径读回、线性 EXR 和亮度极值统计属于后续仪器工作，不伪称已实现。
- 材质/数值/构建通过不等同游戏收敛通过；本轮产物用于验证已确认错误修正和新的路径分解。

## 证据记录

- 起点为 0.3.5，用户游戏验收失败；此前研究见 `../specs/2026-09-10-firefly-path-reassessment.md`。
- 新增 CodeGraph 索引存在；已尝试源码探索，Slang 仍需按文件直接核查。
- 材质 RED：旧生产11个失败子例；GREEN 后继续加入 LOD读取 RED/修正、标志位与消费负面测试。
- 能量 RED：full Lambert 白炉首例1.85885738；归一化预算 GREEN：75组最大0.999770704，互易/归一化/有限值通过。实际RGB乘法、5个输出消费点的10个变异被拒绝。
- 能量模型：A(c)=1-(1-cmin)^5，cmin=c/sqrt(2*(1+sqrt(1-c*c)))；diffuseScale=(1-F0)*A(V)*A(L)/C；C=-15/8+121*sqrt(2)/63≈.8411879531，代码向上舍入.8411881。
- 镜面定向反射率<=U(V)=1-(1-F0)A(V)，漫反射积分<=1-U(V)，在有效方向、albedo/F0<=1前提下守恒。以反射率上界替代精确积分，仍为保守近似，非完整多次散射模型。归一化耦合思路参见 [Kelemen / Szirmay-Kalos](https://diglib.eg.org/items/5265310d-af0e-4015-9cc9-8c380af17fed)。
- 薄玻璃 RED 后，抽取生产walker的1/2/4接口估计均值0.765936/0.586658/0.344168符合参照；预算、opaque/water遮挡、payload恢复以及4种真实函数变异通过。CPU模拟trace，不是GPU场景测试。
- 诊断 RED：旧policy在11/13分类失败；GREEN覆盖400种视图转换、10个实际输出绕过变异、4个真实接口标志变异及状态保留/重置。
- 独立复核发现玻璃LOD依赖采样lobe：已用trace-only bit16统一离线玻璃LOD0/overlay固定足迹，无ABI变动。实时保留原过滤，远距花纹可能更锯齿。
- 独立复核提醒实时guide配对风险：能量约束限定offline编译分支，实时BRDF与guide一同保留。
- 旧源码契约因新增pathFlags参数失败，已同步正确接口并保留输出/权重检测。构建父进程有重复Path变量；改由独立Windows PowerShell调用现有脚本，子进程检查PathVariableCount=1，未修改系统环境。
- 2026-09-14首轮native/Java/Slang/SPIR-V build成功（61秒）；补齐LOD和offline能量范围后再次构建，最终结果见下方包记录。
