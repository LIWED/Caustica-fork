# 间接反射平滑实验 — 0.3.14，2026-09-20

## 为什么继续做这个实验

- 用户补充：ITRP 更快形成平滑画面，磨砂/颗粒感更少。这既可能来自更低的间接光方差，也可能涉及不同的反射外观，不能直接归因于累积算法。
- 继续检查 ITRP：`Lib/GbufferData.glsl:159` 将水标为光滑，167 行将极低粗糙度玻璃标为光滑；`SpecularTracer.glsl:67` 的对应分支直接使用镜面方向。其反射命中着色又使用缓存和屏幕复用。它并不是简单地把所有材质磨糊。
- 当前实验借鉴“降低难采样间接反射的尖锐程度”，并不照搬 ITRP 的裁剪采样。普通 PBR 在第一次可见交互处仍使用原粗糙度。

## 游戏选项

- 视频设置 → **离线间接反射平滑**：关闭（默认）、轻度、较强。
- 仅在离线真正累积时生效；切换清空旧累积。关闭保留原传输，不改变实时渲染。
- 相机开始、以及仅经过水/玻璃理想界面的路径不调整粗糙度。经历普通非 delta 散射或粒子漫散射后，后续普通 PBR 才使用调整后的粗糙度。
- 对微表面参数 alpha=roughness²，在 alpha<0.3 时采用 `clamp(2*alpha, floor, 0.3)`；轻度 floor=0.04，较强 floor=0.1。采样、BRDF、PDF、MIS 及后续光锥共用同一有效参数。
- 首个可见表面的粗糙度保持，但其收到的间接照明仍可能改变。该选项有偏，可能降低间接高光、焦散和亮度，不是完整无偏收敛修复。
- 水/玻璃自身的反射折射模型未调整；直接可见表面的采样噪声、几何偏移和漏光也不是此实验的修复目标。

## 可重现数值实验

- `scripts/test_indirect_regularization.py` 抽取实际 Slang 策略、FP32 GGX/BSDF/混合 PDF，生成 C++ 实验。
- 场景为漫反射接收面 → 平行金属面 → 小圆形光源；无遮挡、无纹理、无水玻璃。接收面余弦采样，金属面进行光源/BSDF 双采样与 MIS。
- 2 个原始粗糙度 × 2 个光照角度 × 3 个模式，共 12 组，每组 150 万条样本。独立双精度 NDF 数值积分利用互易性估算均值参考，有限小光源使用中心方向近似，并显式允许近似误差。

## 最小游戏对照

1. 重启候选版本，在原先满屏颗粒的反光房间使用**源画面 0**，保持相机、分辨率、时间、曝光和反弹次数不变。
2. 先“关闭”累积到约 1000/3000 样本，再切“轻度”，等待重新达到相同样本；同时记录耗时。对比颗粒、亮度以及反射细节，不仅数白点。
3. “较强”用于检查趋势和画质代价，不必直接作为常用设置。随后再看人工光源室内和原游戏场景；水池保留作回归。
4. 若轻度与关闭几乎一样，不能由此要求无限加大强度，应回到贡献来源和几何/法线排查。无需再依次截取全部诊断编号。

## 后续反馈

- 用户分别累积到 30000 样本：轻度明显优于关闭，较强最平滑，但仍有亮点、磨砂感且收敛慢。此实验仅部分有效，不能标记整体问题已解决。后续 0.3.15 检查普通反射采样分配，见 `docs/OFFLINE_LOBE_SAMPLING_2026-09-20.md`。
