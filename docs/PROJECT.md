## 0.3.2 功能状态

- 开启离线渲染后，移动视角和等待静止期间继续显示实时 FP16 画面，游戏时间保持运行。
- 视角连续静止满 2 秒后才请求冻结，并在冻结确认后进入离线 FP32 累积。
- 视角再次移动会立即回到实时画面；仅当冻结由 Caustica 创建时才自动解冻，不会解冻玩家手动冻结的世界。
- DLSS Ray Reconstruction 和 2x 帧生成由“当前帧是否真正累积”控制：移动、等待静止和等待冻结阶段遵循用户原设置，仅累积阶段关闭。
- 冻结与解冻任务带会话和代次检查，旧异步任务不能在移动后重新冻结世界。
- 修复离线累积只到 2 SPP 就返回“保持静止”并不断循环：实时/离线管线切换时，如果方块图集来源未改变，则直接复用现有 LabPBR 视图，不再重建材质图集或误触发地形场景版本变化。
- 首次初始化、方块图集来源变化或 LabPBR 视图缺失时仍会重建材质；真实地形、光源和资源包变化仍会更新 `sceneRevision` 并清空不兼容的离线历史。

- 实时路径反弹范围为 2–16，默认 4。
- 离线路径反弹独立设置为 2–32，默认 8；只在真正累积样本时生效，移动和等待冻结阶段仍使用实时值。
- 改变离线反弹次数会重置离线历史，避免不同光照深度的样本混合。
- 离线模式下“每像素采样数”表示每帧批量；相同总样本数下，将它调低不会固定降低最终质量。
- 离线静态光源使用半径 2 section 的局部光源表，并以局部 90% / 全局 10% 的无偏混合方式采样。
- 局部 NEE 与 BSDF 命中发光三角形的 reciprocal MIS 使用同一选择概率。
- 发光 cutout 三角形的权重包含全部唯一动画帧的 alpha 覆盖率。
- 离线 trace 与历史缓冲使用 RGBA32F；实时 trace 和显示 resolve 保持 RGBA16F。
- 每个离线 SPP 使用全局样本编号生成独立的低差异主射线和路径随机种子。
- 写入离线 trace 前逐通道拒绝负值、NaN 与 Inf，不启用默认亮度裁剪。
- `frame.offlineAccumulate` 已注册，并由静态契约检查所有 FRAME 阶段名。
- 视频设置中的 2x 帧生成开关可即时生效。

## 已知限制

- 较高反弹次数会显著降低每秒累积样本数；离线 16–32 次主要用于静态高质量输出。
- 光源方块的显式光照目前只在真正离线累积时生效；实时支持不属于本阶段。
- 发光实体、手持光源及仅由 LabPBR 定义的特殊发光区域未进入静态光源表。
- 静态光源变化仍会等待 GPU 空闲并全量重建；增量 section 发布留待后续优化。
- 帧生成仅支持 2x；更高倍数存在崩溃风险。
- 实时/离线模式首次切换需要重建匹配的 GPU 图像与管线，可能出现一次短暂停顿。
