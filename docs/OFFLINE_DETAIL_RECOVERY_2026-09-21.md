# 0.3.16 细节损失复盘与 0.3.17 修正

## 验收失败与可重现原因

- 用户报告0.3.16白点和颗粒减少，但细节几乎消失，甚至不如实时画面。判定该方案未通过画质验收，不能将其描述为收敛问题已解决。
- 固定强度的三级空间平滑没有读取样本方差，因此即使累积图像已经稳定，也会持续平滑低对比细节。第一命中表面的法线/深度不能标记反射内部所有细节；漫反射加镜面颜色再夹取也会削弱材质区分。
- 新增回归使用相同法线、深度、材质引导的无噪声0.45/0.55细棋盘。执行原GLSL核心后，只保留0.371211倍的对比度。该数字是合成测试结果，不是用户游戏画面损失比例。
- 上版验证集中于常量、大块边界和去噪效果，缺少稳定低对比细纹理、同表面真实点高光及低噪声细节测试。这是验证缺口；本次补齐。

## 0.3.17 的变化

- 撤掉固定三级大范围平滑。默认关闭新的 **离线自适应降噪（实验）**，配置键为 `offline.denoise-adaptive`，启动覆盖为 `caustica.rt.offline.denoiseAdaptive`。
- 旧 `offline.denoise=true` 不会启用新实验；旧配置不删除、不修改，仍可供回退版本使用。这样升级后先恢复原始累积画面。
- 单独存储RGB加权中心二阶矩和累计帧数。原始HDR平均表达式保持不变，统计输出不写回原始颜色。
- 在每帧均值方差满足 `Var(x_i)=sigma²/SPP_i` 且帧间独立的假设下，令W为总样本数、K为帧数，则均值方差估计为 `M2/((K-1)*W)`。这支持变SPP帧的加权统计。
- 实际子像素序列有相关性，重尾也会令有限样本统计不稳定；因此只能称为估计，不是置信保证或自动识别真实光源的证明。
- 先要求像素的不确定性足以解释异常亮度，才运行孤立亮点处理；亮度标准差使用考虑潜在RGB相关性的保守界，而非假装三个颜色通道独立。
- 然后仅做一个半径2像素的局部重建，处理力度由估计噪声与原始邻域对比度决定。对比度始终读取未经亮点处理的历史，避免先裁掉亮点又低估对比度。
- 方差为零、不足32累计帧、统计无效的中心像素均透传，两个阶段都适用。邻居有噪声不能强制平滑一个已稳定的中心。
- NaN/Inf在夹取之前检查；达到原始样本权重上限后，将统计标记无效并跳过重建，不假称继续保持全样本方差估计。原始累积的已有行为不变。

## 资源、开关与范围

- 原来的第二张临时图改为持久统计图，另一张保留为临时颜色图；新增统计没有比0.3.16增加图像数量。累积管线4绑定，重建管线9绑定、2组固定描述符、16字节推送常量。
- 统计图随原始累积重置、随输出资源销毁；关闭重建时继续统计，以便以后开启立即使用已有信息。原始曝光顺序、诊断旁路和无重置开关保持。
- 最后阶段只写最终显示图，虽绑定同一临时图为输入/候选输出，该分支没有临时图写入。每阶段有内存屏障。
- 路径追踪、材质粗糙度、随机种子、原始累积目标不改。此版优先避免细节损失，仍可能保留更多噪声；不能承诺原始光路更快收敛。
- 参考 [SVGF原始研究](https://research.nvidia.com/labs/rtr/publication/schied2017spatiotemporal/) 使用时间/空间方差控制重建。此处只采用统计驱动的设计原则，没有实现完整SVGF，也没有集成OIDN或学到ITRP全部缓存行为。

## 验证

- `test_offline_denoise_detail.py`：稳定细棋盘对比度0.999997；叠加少量噪声后0.996882；稳定小高光、噪声邻居旁的稳定中心保留。31帧/无效统计旁路，32帧可处理不稳定尖峰。恢复固定噪声假设的负对照被拒绝。
- `test_offline_moments.py`：运行实际累积GLSL核心，100个变SPP批次与独立二阶矩参考一致；原平均与旧表达式逐值一致。重置、权重上限、NaN/Inf、矩/均值溢出测试通过。
- 4000次独立模拟中，估计均值方差0.000983904，重复实验测得0.00100856，在预设6%容差内。此验证的独立采样前提不等于游戏采样前提。
- 原去噪合成图均方误差12.8981→0.00712838；排除亮点后颗粒误差为输入的0.35426。比0.3.16去噪力度小，符合保守处理方向，不用于宣称游戏降噪比例。
- 引导边界、HDR、天空、等亮度彩色边缘、负对照、显示/统计接线、原离线累积、贡献诊断、间接平滑切换回归通过。
- 独立审查发现非有限矩先夹取会隐藏异常，已用失败回归复现并修正。正常绑定、资源生命周期和原始历史分离未发现阻断问题。
- 尚无0.3.17游戏GPU画质验收。辅助图仍是末次采样属性，透明/反射引导局限、极端尾部和空间相关噪声仍可能导致误判。

## 简短对照

升级重启后默认显示原始画面。保持原机位、平滑档位与其他设置；只有在愿意比较时开启新的自适应降噪，确认砖缝、细纹理、镜中物体和小灯是否保留。开关不清空样本，无需再分别等待30000样本。若仍有明显细节损失，保持关闭，不把更干净但更糊的画面当作通过。
