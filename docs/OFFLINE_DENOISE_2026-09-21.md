# 离线显示降噪 — 0.3.16

**后续验收失败：用户报告严重细节损失。以下为历史实验记录，不是当前推荐。0.3.17默认关闭并替换固定滤波，见 `docs/OFFLINE_DETAIL_RECOVERY_2026-09-21.md`。**

## 为什么改变本轮目标

- 用户反馈：0.3.15 与上版在速度和画面上都没有可感知差别。本轮不把局部数值方差下降算作游戏改善，优先处理白点与磨砂感。
- 用户明确接受：新增可关闭的离线降噪，允许一定细节损失，保留原始对照。此前的间接反射平滑选项继续保留。
- 新日志 `caustica-paths-20260921-171336-149.jsonl`：768 条阈值记录，代次 1/2/3 对应关闭/轻度/较强；全部类别 10，无透明界面历史。最大贡献分别 4390.76、1387.84、264.45。
- 日志记录机位一致，854×480，24 次反弹。采集范围只有 256–264 样本，各代次最多 256 条、阈值 32；不能用这些最大值衡量最终画面噪声或声称画面已改善。回放最大相对误差 5.51e-7，无非有限值和类别不一致。
- 前一天 `caustica-paths-20260920-231232-717.jsonl` 同样有 1024 条类别 10 记录。说明这批普通表面光路仍有高贡献尾部，不证明所有场景只有太阳噪声，也没有排除几何/法线问题。
- 汇总保存在 `build/surface-lobe-sampling/game-20260921.json` 和 `game-20260920-late.json`，含输入哈希。

## 选项与工作方式

- 视频设置新增 **离线画面降噪**，默认开启；仅在离线累积且调试视图关闭（源画面 0）时生效。
- 第一步在兼容表面的 5×5 邻域中使用亮度分位数识别孤立极亮点，按比例调整 RGB，保留色相。至少需要 8 个兼容邻居才执行。
- 随后用三个空间滤波阶段减少颗粒，采样间距为 1/2/4 像素；结合法线、硬件反向深度、漫反射加镜面颜色及 RGB 差异限制跨边界混合。
- 两张独立 RGBA32F 临时图像交替写入，最终写入已有显示目标；原始 FP32 累积只读，永不回写降噪结果。没有修改路径追踪、粗糙度、随机数序列或累积公式。
- 开关不参与历史签名，因此不会主动清空样本；下一帧关闭时直接显示持续保存的原始累积。正常渲染期间样本仍会增加，因此是同一累积过程的即时对照，不是冻结同一张图。
- 曝光统计在降噪之前读取原始累积，避免开关引起额外全局曝光偏移。贡献视图 8–21 和其他诊断视图保持原始值。
- 该实现是实验性空间滤波，不是 OIDN、DLSS-RR，也不是 ITRP 的辐照度缓存。官方 [OIDN 文档](https://www.openimagedenoise.org/documentation.html) 将 HDR 颜色及材质/法线辅助信息用于蒙特卡洛图像重建；这支持独立重建阶段的方向，不代表本实现达到其质量。

## 实现与安全边界

- 新增 `shaders/display/offline_denoise.comp` 与 `RtOfflineDenoisePipeline`；使用四组创建时固定的描述符，录制期间不重绑定资源内容。
- 每个滤波阶段之间有内存屏障；窗口/离线状态改变沿用等待设备空闲后的销毁流程，关闭整个渲染器也释放资源。初始化失败释放已创建的管线对象，记录警告并保留原始累积。
- 配置键 `offline.denoise`，启动覆盖 `-Dcaustica.rt.offline.denoise=false`。开关通过现有布尔设置保存；没有新增热键或隐藏传输模式。
- 现有帧统计新增 `frame.offlineDenoise` 阶段，供后续性能跟踪；没有据此声称测到了 GPU 加速。
- 两张临时图像额外占用 32 字节/像素，1080p 约 63.3 MiB，4K 约 253.1 MiB。离线资源创建时分配，关闭开关后停止滤波，但临时图像保留到离线资源销毁。

## 验证结果与限制

- 新测试把实际 GLSL 核心通过图像 API/向量类型替身在 CPU 上运行；不另外重写滤波公式。覆盖常量 HDR、1×1/2×3 图像、边界、孤立亮点、密集颗粒、深度/法线/漫反射/纯镜面颜色边界、零法线天空、等亮度彩色反射边缘和大块高光。
- 合成颗粒加稀疏亮点图像均方误差从 12.8981 降至 0.002636；单独排除亮点统计的颗粒误差为输入的 0.1372。仅描述该合成测试，不是游戏噪声下降比例。
- 恢复透传的负对照无法减少颗粒；移除辅助边界判断的负对照会抹掉独立小表面，均被拒绝。
- 接线测试覆盖原始曝光顺序、源视图限定、历史只读、无重置开关、资源绑定/屏障/销毁及四个破坏性负对照。原离线累积、贡献诊断和间接平滑历史切换回归通过。
- 独立代码审查未发现正常执行路径阻断问题；按反馈补充了天空、纯镜面材质、等亮度彩色边缘测试，并修正辅助图像用途注释。
- 原始估计器的真实收敛速度没有因此提高。滤波有偏，真实的单像素高光/小光源可能被当作异常点；细纹理、细焦散、反射边缘可能变软。
- 辅助图像仍来自最后一次主射线样本，未做无噪声平均；透明物体的表面/透射内容也不完全一致，边缘可能残留颗粒或抖动。宽区域噪声和亮点簇未必消除。
- CPU 测试与着色器编译不等于游戏 GPU 画质/稳定性验证；尚未取得本版运行反馈。

## 复测

1. 重启 0.3.16，在原反光房间使用源画面。保持此前较强档及机位、时间、曝光等设置。
2. 先累积约 500–2000 样本，开关“离线画面降噪”比较白点、磨砂感与纹理/反射细节。开关本身不清空历史；注意进入菜单或移动相机仍可能影响正常累积状态。
3. 如有明显改善，再检查实际游戏场景、玻璃、水体和细小灯光。无需先重复 30000 样本或遍历诊断编号。
4. 若大片噪声仍在或细节损失过大，保留原图与降噪图作为后续重建/缓存设计依据，不能直接把滤波输出称为正确收敛的参考图。
